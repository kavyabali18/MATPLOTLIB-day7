# Data Visualization using Matplotlib

## Overview
This project demonstrates various data visualization techniques using the Matplotlib library in Python. Different types of charts and plots are created to understand how graphical representations help in analyzing and interpreting data effectively.

## Technologies Used
* Python
* Matplotlib
* NumPy
* VS Code

## Visualizations Included
* Line Chart
* Bar Chart
* Histogram
* Scatter Plot
* Pie Chart
* Box Plot
* Heatmap

## Project Description
The project uses simple sample data directly within the Python code to generate multiple visualizations. Each graph represents a different method of presenting and understanding data patterns, comparisons and distributions.

## Learning Outcomes
* Understanding basic data visualization concepts
* Creating plots using Matplotlib
* Customizing charts with titles, labels and colors
* Visualizing data in different graphical formats

## Conclusion
This project helped in learning how Matplotlib can be used to create clear and informative visual representations of data in Python.
